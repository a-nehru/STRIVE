# Cozy Fruit Merge: the fruit pictures

From **Fluent Emoji** by Microsoft (https://github.com/microsoft/fluentui-emoji),
the 3D style, under the **MIT License** (`LICENSE` in this folder, kept with the files
as the licence asks). Downloaded 31 Oct 2026, unchanged.

| File | Fluent Emoji asset |
|---|---|
| strawberry.png | Strawberry/3D/strawberry_3d.png |
| grape.png | Grapes/3D/grapes_3d.png |
| orange.png | Tangerine/3D/tangerine_3d.png |
| apple.png | Red apple/3D/red_apple_3d.png |
| peach.png | Peach/3D/peach_3d.png |
| pineapple.png | Pineapple/3D/pineapple_3d.png |
| melon.png | Melon/3D/melon_3d.png |
| pumpkin.png | Jack-o-lantern/3D/jack-o-lantern_3d.png |

`js/fruit.js` (`FLUENT_FIT`) scales each so its body, stems and leaf tips left out
(measured from the picture's alpha), fills the fruit's physics circle.
